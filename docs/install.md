There are two easy ways to get Skykatana. Either:

> :material-arrow-right-box: `:::py3 pip install skykatana`

or

> :material-arrow-right-box: clone the [repo](https://github.com/samotracio/skykatana), switch to the pacakge directory and do `pip install -e .`

This last form has the advantage that you will get the latest version and example notebooks.


### Dependencies

* [lsdb](https://github.com/astronomy-commons/lsdb) (data serving framework)
* [healsparse](https://github.com/LSSTDESC/healsparse) (map definition)
* [healpy](https://github.com/healpy/healpy) (healpix pixel math)
* [fitsio](https://github.com/esheldon/fitsio) (io framework)
* [tqdm](https://github.com/tqdm/tqdm) (ui enhancement)
* [ipyaladin](https://github.com/cds-astro/ipyaladin) (interactive visualization)
* [pillow](https://github.com/python-pillow/Pillow) (image_to_mask)
